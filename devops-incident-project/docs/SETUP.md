# Local AI DevOps agent: setup

Everything runs on your machine. Evidence is sent only to Ollama on `127.0.0.1`; there is no
hosted AI API, and the client refuses any non-local address.

## 1. Requirements

| Need | Check |
|---|---|
| Python 3.9+ (use the `py` launcher on Windows; plain `python` may be 2.7) | `py -3 --version` |
| kubectl with a working context (Docker Desktop Kubernetes is fine) | `kubectl config current-context` |
| Docker (optional, for the `docker` command) | `docker ps` |
| Ollama and one model | steps below |

No Python packages are needed (standard library only).

## 2. Install Ollama and a model

```powershell
winget install --id Ollama.Ollama --silent
ollama pull phi3.5          # MIT licensed, 3.8B parameters, about 2.2 GB, fine on CPU
ollama list                 # phi3.5:latest should be listed
```

Other open-source models work too (`qwen2.5:7b` is Apache-2.0 and stronger but slower on CPU).
Choose with `--model <name>` or `$env:OLLAMA_MODEL = "qwen2.5:7b"`.

Check the link between the agent and Ollama:

```powershell
py -3 -m incident_agent llm-check
```

## 3. Run diagnostics (read-only)

```powershell
cd devops-incident-project

py -3 -m incident_agent k8s    --namespace food-delivery --deployment food-delivery-ui
py -3 -m incident_agent ci     --ci-repo Ganeshh01/flutter-prod --ci-branch feature/devops-ci-pipeline
py -3 -m incident_agent docker --docker-container food-delivery-ui-test
py -3 -m incident_agent health --health-url http://127.0.0.1:8085/healthz
py -3 -m incident_agent diagnose --health-url http://127.0.0.1:8085/healthz `
    --docker-container food-delivery-ui-test --ci-repo Ganeshh01/flutter-prod --ci-branch feature/devops-ci-pipeline
```

Add `--llm` to any of them for the local model's analysis:

```powershell
py -3 -m incident_agent k8s --llm
```

Try it on a ready-made broken system without touching your cluster:

```powershell
py -3 -m incident_agent k8s --bundle examples\crashloop.json --llm
```

## 4. What the output means

* The **rule-based diagnosis** is always printed first and does not depend on the model.
* **AI ANALYSIS** is generated by the model and then validated:
  * `FACT (cites existing evidence)`: the cited evidence ids exist.
  * `UNSUPPORTED`: the model called it a fact but cited nothing, or cited ids that do not exist.
  * `ASSUMPTION`: the model said it is a guess.
* Model commands are **never run**. Read-only ones are listed as verification commands for you to run;
  anything else is labelled `NOT RUN`.
* If Ollama is down, not installed, or answers with invalid JSON, you get the rule-based report and a message.

## 5. Acting on a suggestion

Without `--interactive` nothing is ever executed. With `--interactive` each rule-generated command is
shown and runs only if you type `yes <action id>`. Environment-changing commands are limited to
`kubectl -n <ns> rollout restart|undo deployment/<name>`. Every step is recorded in `incident-audit.jsonl`.

## 6. Privacy

Before anything is sent to the model, evidence is sanitized: credentials, tokens, private keys,
e-mail addresses and long token-like strings are masked, control characters removed, each item is
size-limited, and only `id`, `source`, `summary` and a short `excerpt` are sent (never raw data).
Log text is quoted as data inside `<evidence>` tags and the model is told never to follow it.

## 7. Tests

```powershell
py -3 -I -m unittest discover -s tests -t . -v
```

The tests use fakes and a fake Ollama server on localhost: no cluster, network or model needed.
The quality of a real model's diagnosis is not covered by these tests; judge it by running `--llm`.

## Troubleshooting

| Message | Fix |
|---|---|
| `Ollama is not reachable` | Start it: `ollama serve` (or open the Ollama app). |
| `model 'phi3.5' is not installed` | `ollama pull phi3.5` |
| `refusing to send data to ...` | `--ollama-url` must be `http://127.0.0.1:<port>` or `localhost`. |
| `not valid JSON` | The model answered badly. Retry, or use a larger model. |
| Slow answers | CPU-only machines take 30 to 120 seconds per analysis. Use a smaller model. |
